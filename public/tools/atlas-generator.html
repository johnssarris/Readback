Readback — Glyph Atlas Generator

Renders the 95 printable ASCII characters (0x20–0x7E) into a sprite sheet + manifest for the glyph-matching pipeline. The font is …, bundled with the app — the same face the editor being photographed has to be set to. Use "Load local font file" to render from your own copy instead, if you want a pixel-exact match to what is installed on your machine.

npm run atlas does the same thing headlessly and writes straight to public/atlas/. Use that unless you are rendering from a local font file.

Cell size comes from the font's own advance width and line box.
